# sqr-jira-bundle

Official Siliqun Rotor Integration Bundle for Atlassian JIRA Cloud & CLI.

## Capabilities
- RESTful issue creation with automatic plain-text to Atlassian Document Format (ADF) pre-transform.
- RESTful issue retrieval with 99.1% payload reduction post-transform.
- Local CLI issue view runner executing strictly on developer workstation.
- 5 Studio Teach test fixtures.
